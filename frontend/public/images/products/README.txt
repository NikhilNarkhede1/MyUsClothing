PRODUCT PHOTOS
==============
Each product shows the photo with its own file name from this folder:

  men-oxford-button-down-shirt.jpg
  men-blue-checked-casual-shirt.jpg
  men-pink-linen-shirt.jpg
  men-white-mandarin-collar-shirt.jpg
  men-teal-casual-shirt.jpg
  men-grey-formal-shirt.jpg
  boys-colour-block-casual-shirt.jpg
  boys-white-oxford-shirt.jpg
  boys-multicolour-print-shirt.jpg
  boys-mustard-graphic-t-shirt.jpg
  boys-white-mandarin-collar-shirt.jpg
  boys-dot-print-half-sleeve-shirt.jpg

The file name always comes from the product name: lowercase, spaces become "-".
  "Men Oxford Button-Down Shirt"  ->  men-oxford-button-down-shirt.jpg

To CHANGE a photo: replace the file, keeping the same name (.jpg, .jpeg, .png or .webp), then refresh the browser.
To ADD or RENAME a product: edit the list in backend/src/main/java/com/shop/DataLoader.java and restart the backend.
Use portrait photos (4:5, e.g. 800 x 1000 px) under about 300 KB. Only use photos you own or are allowed to use.
A product with no photo file shows a simple drawing instead.
